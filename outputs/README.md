# 面试产出目录

按岗位模板生成的候选人材料放在本目录。当前仅有目录说明，历史候选人范例未迁入。

本目录中的实际候选人材料默认只保留在本机，由 [.gitignore](../.gitignore) 排除；仅本说明文件进入版本管理。

| 材料 | 文件名 | 内容 |
|---|---|---|
| 测开候选人画像 | `候选人画像-<姓名>-测试开发.md` | 简历经历拆解、待验证声称、面试侧重点 |
| 测开面试官材料 | `面试报告-<姓名>-测试开发.md` | 50 分钟安排、问题与追问、参考实现、观察点；面试后追加证据和评分 |
| 测开候选人编程题面 | `编程题-<姓名>-测试开发.md` | 题目、输入输出、示例、限制；不含答案、考察点或评分提示 |
| 功能测试面试官材料 | `面试题列表-<姓名>-游戏测试.md` | 20 分钟题单、参考要点和追问；面试后追加观察证据与建议 |

同名或多轮面试可在文件名前增加日期、文件名后增加轮次，避免覆盖既有记录。模板中的 `<姓名>` 等占位符生成时替换。

每份材料注明岗位、招募类型、面试日期（未排期则写待定）和材料状态（准备中 / 已确认 / 已面试）。面试前的计划和推测、面试后的回答证据与结论分开记录。

测开面试官材料在面试前是安排与题单，不是已完成的评价。没有实际回答证据时，评分和最终建议留空。功能测试暂不生成量化总分。
